# CampusHub Connect

Create a modern student website called CampusHub.

Tagline: “Your Campus, Your Space.”

Make it clean, premium, youthful and simple. Use a dark navy + lavender + blue + white color theme, rounded cards, soft shadows, modern icons and subtle animations.

Create these main pages:

Home

CampusHub logo

Hero section with a beautiful campus image

“Your Campus, Your Space.”

Buttons: Get Started, Explore Campus

Feature cards for Events, Announcements, Resources, Lost & Found

Student Dashboard

Good Morning message

Upcoming Events

Latest Announcements

Assignment reminders

Quick Access cards

Events

Event cards with image, date, time, location and Register button

Categories: Technical, Cultural, Sports, Workshop

Resources

Notes, Question Papers, Lab Materials and Placement Resources

Search and category filter

View/Download buttons

Lost & Found

Lost and Found item cards

Add item button

Search and filter

Campus Map

Simple attractive campus map

Show Library, Labs, Canteen, Hostel, Auditorium and Departments

Profile

Student photo

Name, Department, Year, Student ID

Edit Profile button

Admin Dashboard

Manage announcements

Manage events

Manage resources

Manage lost & found posts

Show basic statistics

Add simple Login and Signup pages.

Use sample data and attractive placeholder images.

Make the website fully responsive for desktop and mobile.

Focus on beautiful UI and working navigation first. Keep the project lightweight and simple.
